# e-카탈로그 → 제품 목록 추출 (Winmate 제품 DB)

삼성 B2B e-카탈로그(samsung.aiibook.net/b2b)의 쪽별 텍스트에서 **제품 목록**을 뽑아 JSON 으로 저장한다.
나중에 samsung.com/business 사이트 제품 DB와 모델코드로 맞춰 보고, 사이트에 없는 제품은 앱의 제품 탐색기에 '카탈로그 제품'으로 올린다.
그래서 **원문에 있는 것만** 옮긴다. 이름 · 모델코드 · 수치를 지어내거나 고치지 않는다(오탈자도 원문 그대로, 단 줄바꿈으로 끊긴 모델코드는 이어 붙인다).

## 도구
- 쪽 텍스트 보기: `python3 proddb/ecat/show.py <Dir> [시작쪽] [끝쪽]` (텍스트가 없는 쪽은 빠져 있음 — 이미지 전용 쪽)
- 사이트 분류 이름 목록: `proddb/ecat/site_categories.txt`
- 쪽 이미지가 꼭 필요하면(표가 텍스트로 깨진 경우 등): `https://samsung.aiibook.net/b2b/catImage/<Dir>/<NNN>.jpg` (3자리, 001부터)를 curl 로 받아 Read 로 본다. 꼭 필요할 때만.

## 무엇을 한 항목으로 잡나
- 카탈로그가 제품으로 소개하는 단위 하나 = 항목 하나. 보통 **제품명 / 시리즈 하나**(예: "DVM S2 실외기 냉난방 표준형", "갤럭시 북6 Pro 엔터프라이즈 에디션", "JBL Control 25-1").
- 같은 제품의 사이즈 · 용량 · 색상 모델은 한 항목의 `models` 에 모두 넣는다(사양표 행의 모델코드 전부).
- 하드웨어 · 소프트웨어 라이선스 · 서비스 상품 · 액세서리(모델코드가 있는 것) 모두 포함.
- 빼는 것: 경쟁사 제품, 설명용 예시표의 이름 없는 수치, 같은 카탈로그 안에서 이미 뽑은 항목의 반복(쪽만 `pages` 에 더함), 일반 기술 용어.

## JSON 형식 (배열)
```json
[{
  "id": "ec<Dir>_<3자리 순번>",            // 예: ec297_014 (순번은 이 Dir 안에서 1부터)
  "name": "원문 제품명",
  "series": "시리즈 / 제품 라인 이름(원문, 없으면 null)",
  "models": ["모델코드 원문", "..."],         // 원문에 모델코드가 없으면 []
  "category": "분류",                         // site_categories.txt 중 맞는 것이 있으면 그 이름 그대로, 없으면 카탈로그의 분류 표현(예: '시스템에어컨 > 실내기 > 덕트형', '하만 프로 오디오 > 스피커')
  "family": "디스플레이 | 공조 · 에어컨 | 모바일 · PC | 프린팅 | 주방 · 리빙 가전 | 조명 | 오디오 | 기타",
  "specs": [["항목", "값"], ...],             // 원문 사양 최대 8개(대표 모델 기준 또는 '범위'), 단위 포함 원문 그대로
  "features": ["원문 기능 문구", ...],        // 최대 4개, 짧은 원문 문구(한 줄)
  "dir": "<Dir>",
  "pages": [쪽 번호, ...],                    // 이 제품이 나오는 쪽(정수)
  "note": "필요하면 한 줄(예: '2024 리플릿 모델', '사양표 일부만 텍스트')"
}]
```

## 진행
1. 맡은 Dir(과 쪽 범위)을 처음부터 끝까지 읽는다. 긴 문서는 20~40쪽씩 나눠 본다.
2. 항목을 모은 뒤 `proddb/ecat/extract/<맡은 이름>.json` 으로 저장한다(UTF-8, ensure_ascii=False). 맡은 Dir 이 여럿이면 한 파일에 모두.
3. 저장 후 `python3 -c "import json;d=json.load(open('<파일>'));print(len(d))"` 로 읽히는지 확인하고, 아래를 점검한다:
   - 모든 `models` 값이 해당 `pages` 원문에 실제로 있는지(파이썬으로 문자열 검색) — 없으면 고치거나 뺀다.
   - `id` 중복 없음, `family` 는 위 8개 중 하나.
4. 끝나면 짧게 보고: 항목 수, 모델코드 수, 원문 대조에서 고친 것, 애매해서 뺀 것.

다른 파일은 고치지 않는다. 사이트 수집 · 앱 코드는 건드리지 않는다.
