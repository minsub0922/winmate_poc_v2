# 카탈로그 제품 사진 잘라내기 — 작업 규칙

Winmate 제품 DB의 '카탈로그 전용' 제품(삼성 e-카탈로그에만 실린 제품)에는 사진이 없다.
각 제품이 실린 e-카탈로그 쪽 이미지에서 **그 제품의 실제 사진 영역**을 잘라 채운다. 지어내거나 다른 제품 사진을 쓰면 안 된다.

## 입력
- 배치 파일 ``$PHOTO_WORK/batches/bNN.json`` — 제품마다 `id`, `name`, `model`/`models`(모델코드), `cat`, `pages`(이 제품이 나오는 쪽 키, 예 `297_037` = 카탈로그 Dir 297의 37쪽), `catalog`, `specs`, `feats`, `note`
- 쪽 이미지: `$PHOTO_WORK/pages/<키>.jpg` (해당 카탈로그의 모든 쪽이 있음 — 배치에 없는 쪽도 열어 봐도 됨)

## 도구 (`python3 build/photo_tool.py ...`) — 좌표는 항상 쪽 크기의 퍼센트(x0 y0 x1 y1, 왼쪽 위가 0)
- `grid KEY` → 쪽 전체 + 5% 격자 이미지 경로를 출력. **Read 도구로 그 이미지를 본다.**
- `zoom KEY x0 y0 x1 y1` → 그 영역 확대 + 1% 격자(5마다 숫자). 좌표를 정확히 읽을 때 쓴다.
- `crop ID KEY x0 y0 x1 y1 [--kind cut|scene|diagram] [--nosnap] [--n 2] [--note "..."]`
  → `crops/ID.jpg` 저장, 출력의 `check` 이미지(왼쪽 = 쪽에서 빨간 상자, 오른쪽 = 잘린 결과)를 **반드시 Read로 확인**.
  흰 바탕/단색 판 위의 물체는 상자 안 물체에 맞춰 자동으로 조여진다(snap). 꽉 찬 사진(장면 · 사진 프레임)이나 snap이 엉뚱하게 자를 때는 `--nosnap`.
  같은 ID로 다시 실행하면 덮어쓴다. 두 번째 사진(선택)은 `--n 2`.
- `none ID "이유"` → 카탈로그 어디에도 이 제품 사진이 없을 때.
- `find DIR "문자열"` → 그 카탈로그에서 문자열(모델코드 · 이름)이 나오는 쪽 목록 + 앞뒤 글.
- `sheet ID ID ...` → 끝낸 결과 모음 이미지(최종 점검용).

## 규칙
1. **그 제품을 찍은 사진만.** 쪽에 여러 제품이 있으면 이름표 · 모델코드 · 표의 같은 행 · 화살표/선 연결로 어느 사진이 이 제품인지 확인한다. 확신이 없으면 그 쪽의 글(이름 · 모델코드)과 사진의 위치 관계를 zoom으로 다시 본다.
2. **제품 사진 영역만** 자른다 — 제품명 캡션 · 모델코드 글자 · 표 선 · 아이콘 · 쪽 장식은 빼고, 제품 전체는 잘리지 않게(손잡이 · 받침 · 리모컨처럼 한 세트로 찍힌 것 포함).
3. 우선순위: 깨끗한 제품 컷(흰/단색 배경) `--kind cut` > 제품이 주인공인 설치 장면 `--kind scene`(제품 부분 위주로) > 서비스 · 솔루션 · 소프트웨어처럼 물건이 없는 항목은 그 항목을 보여 주는 대표 그림/화면 `--kind diagram`.
4. 같은 사진을 쓰는 시리즈(용량 · 크기만 다른 모델 등)는 같은 영역을 각 ID에 각각 crop 해도 된다. 다른 모델의 사진을 '비슷해서' 쓰지는 않는다 — 단, 카탈로그가 그 사진을 이 제품(시리즈)의 사진으로 보여 주고 있으면 된다.
5. 배치의 `pages` 첫 쪽에 사진이 없으면 나머지 `pages`, 그다음 `find DIR "모델코드"`/`find DIR "이름 일부"`로 같은 카탈로그의 다른 쪽(제품 소개 · 라인업 쪽)을 찾는다. 그래도 없으면 `none`.
6. 너무 작은 사진(가로 60px 미만으로 나올 정도)밖에 없으면 그래도 자르되 `--note "작음"`.
7. 각 crop 뒤 check 이미지를 보고 틀리면 바로 고친다. 모든 제품을 끝내면 `sheet`로 배치 전체를 한 번 더 보고(여러 장이면 나눠서) 이상한 것을 고친다.

- none 목록(ID · 이유)
- 확신이 낮은 것(ID · 왜)
