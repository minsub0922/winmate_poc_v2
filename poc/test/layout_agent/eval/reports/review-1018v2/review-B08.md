# B08 검수 — (주)한빛레이더스 프로야구단 한빛파크 전광판·리본보드·컨코스·매점 리뉴얼 (22장)

검수 기준: input.md(메모, 키맨, 요구사항 문서 v2), s01~s22 캡처 전 장 확인, slides_text.md 대조.

## 1. 점수표

| 항목 | 점수 | 한 줄 근거 |
|---|---|---|

## 3. 그 밖의 문제

- 필수 제출물 누락:
  - '개막(2027.3.27) 전 완료 가능한 공정표'가 없음. s02는 기간이 모두 자리표시이고, s20은 유지관리 일정임.
  - '11월 팬페스타와 일정 충돌 없음'을 다룬 곳이 없음.
  - '국내 프로스포츠 구장 구축 레퍼런스'가 없음. s18은 백화점, 면세점, 미디어폴뿐임.
- 메모의 지시 "공단 시설부장 설득용 구조 안전 자료 꼭 넣기"가 빠짐. 철골 하중, 경량 캐비닛, 구조 검토 절차를 다룬 장이 없고, 표의 한 줄 "[대응 방안]"뿐임.
- 메모의 차별화 축이 수치 없이 빠져 있음:
  - '주간 시인성': 휘도(nit) 수치가 한 번도 나오지 않음.
  - '경기 중 장애 대응': 이중화, 예비 모듈, 상주 인력 내용이 없음.
  - 'L사는 가격, 우리는 85% 기술 배점'이라는 전략 메시지가 대표이사용 한 장으로 정리되지 않음.
- 담당자 메모 조각 노출 위험: s05 "R19 구조 안전·유지관리는 공단이", "R18 구장은 시 소유"는 메모("공단이 깐깐하게 봄")에서 나온 문장이 요구사항처럼 들어간 것임. 지금은 잘려서 무해하지만 원문이 나오면 문제가 되므로 삭제할 것. 경쟁사 실명은 언급하지 않아 메모 지시를 지켰음.
- s05~s07 요구 매트릭스: "요구사항 41개"인데 ID가 R02~R52로 41을 넘음. "현재 메인 전광판", "현재 전광판 콘텐츠는", "일정은 시 예산 집행 절차에"처럼 요구가 아닌 배경 문장을 요구로 잘라 넣음. '필수' 열은 R05 외 전부 '권장'임('개막 전 완료'는 필수여야 함).
- s09 "현장 점검 · 인터뷰 기준", s03 "인터뷰 [0]회 · 제안 설명회 질의 기반" — 현장 실사는 11월 둘째 주 예정이고, 그동안은 통화 1회뿐이었음. 하지 않은 절차를 적었음.
- s11: "시설관리공단 협업 최적화" 라벨이 메뉴보드 편집 화면에 붙어 있고, "관람객은 즉시 경기 정보 확인" 아래 본문은 매점 결제 이야기라 서로 맞지 않음. "템플릿 기반 편집" 칩이 이미지 안내 문구와 겹침.
- s13: 부제는 "컨코스 TV 120대 교체"인데 카드는 "스마트 TV [0]대". 컨코스는 경기 중계, 메뉴, 긴급 송출, 원격 일괄 변경이 요구되므로 상업용 사이니지(24/7, CMS 연동)로 제안해야 함.
- s16: POS 행이 두 번 나오고, BMS 조명, 예약·CRM 웰컴 메시지, SSO는 이번 요구와 거리가 멂. 구단 앱 주문·결제 연동만 남기고 정리할 것.
- s22: 마지막 요청 "파일럿 승인 요청"은 고객 일정(제안서 접수 → 합동 PT → 우선협상)과 맞지 않음. 'PT·현장 실사 일정 확정' 등으로 바꿀 것. 제목도 "…한빛파크 디지"에서 잘림.
- s01: 제목이 "컨코/스"로 어색하게 끊기고, 하단 문구가 "한빛파크 메인"에서 잘림. 이미지 없는 표지임.
- 장 번호가 뒤섞임: s12 "10"과 "04", s17 "[00]"과 "02", s16·s20 "[00]".
- 제품·사례 확인 필요:
  - 모델: XHB(실외 LED)와 KM24C(키오스크)는 모델명과 사양(휘도, IP 등급, 크기)을 확인해야 함.
  - s18 "신세계백화점 본점 외벽 2면 총 1285㎡": 수치와 삼성 공급 여부 확인 필요.
  - "강남대로 미디어폴 18대": 삼성 공급 여부 확인 필요.
  - 현대백화점면세점: 사례 내용 확인 필요.
- 자리표시 양: 덱 전체에 약 200개. s04, s05~s07, s14, s15는 거의 자리표시뿐이고, s15는 사실상 빈 장임.

## 4. 잘된 점

- 고객 문서의 평가 배점 5개 항목을 정확히 옮겨 '평가 항목별 대응 근거' 틀을 만든 점(s04)은 수주형 제안서로서 방향이 맞음.
- 키맨 4명의 요구를 직접 인용해 이해관계자별 가치 구조를 잡은 점(s10)은 좋음(내용은 바로잡아야 함).
- 경쟁사 실명을 언급하지 않아 메모 지시를 지켰고, TCO 비교를 '경쟁사 A/C 안'으로 익명화했음(s21).
- s09 '현상 → 직접 원인 → 근본 원인' 구조, s16 시스템 연동 매트릭스와 연동 전제 조건 체크리스트("확인 필요"를 솔직하게 표시)는 실무에서 바로 쓸 만한 틀임.
- 입력에 있는 확정 수치(컨코스 TV 120대, 매점 18곳, 키오스크 36대, 2011년 설치, 운영 인력 2명)는 틀리지 않게 옮겼음.

## 5. 재사용할 장표

- s04: 평가 항목 표. 하단 '가격 20' 행과 '[평가 항목]' 빈 행을 지우고 근거를 채우면 사용 가능
- s16: 연동 매트릭스와 전제 조건. 호텔·BMS 항목 삭제
- s21: TCO 틀. 10년으로 늘리고 근거 없는 −15%와 '3년차 역전'은 제거
- s09: 원인 분석 구조. 사진 교체, 3번 '[내용]' 채우기
- s02, s05~s07: 틀만 재사용. 요구사항을 문서에서 다시 뽑아야 함
