## 3. 그 밖의 문제

- 핵심 제품이 비어 있음: 직바람 민원의 답이 되는 무풍 계열 제품명이 s05 "[제품] 에어컨", s07 "[제품] · [제품] 시스템에어컨", s09 "[제품] 시스템에어컨"처럼 모두 자리표시로 남음. 메모의 '무풍' 판단이 장표에 옮겨지지 않았음. 내부 말투인 "무풍 딱임"은 그대로 노출하면 안 되지만, 제품명은 들어가야 함.
- 메모의 "공청기는 로비/면회실 정도만"이 s08 한 줄("붐비면 환기 · 공기청정 자동 강화")로만 반영되고, 제품 구성과 수량에는 없음.
- 이사장 보고용이라는 점이 약함: 예산은 이사장 결재 사안이고 원장이 '대략적인 그림'을 요청했는데, 규모·예산 범위나 단계별 투자안(시범 병동 → 전체)이 없음. s13 다음 단계도 "감염관리 강화 사양 상세 검토 및 적용" 한 줄뿐임.
- 용어: 메모가 "너무 기술적으로 가지 말 것"이라고 했는데 DMS, ERV, 외기 열회수, 전열교환 같은 용어를 설명 없이 반복함. 이사장용으로는 쉬운 말로 풀어 써야 함.
- s09: 세 번째 카드의 페르소나 자리에 "직관적인 화면으로 간편한 / 쾌적한 실내 환경 유지"가 들어가 구조가 깨짐. 시설 관리팀 카드의 가치는 "환자·보호자·간호사가 만족하는 환경"이라 대상과 맞지 않음. "스마트싱스 통합 제어"와 다른 장의 "DMS"가 섞여 제어 방식이 일관되지 않음(어느 쪽으로 제안할지 확인 필요).
- s11: 수치 카드의 라벨이 어긋남("쾌적한 병원 / 외기 열회수 … 전력 절감", "늘봄요양병원 / 민원 감소", "공기질 개선을 / 환자 만족도 조사 결과"). 사진은 CT 판독 장면이라 기대 효과와 상관이 없음.
- s08: 운영 시간은 "월–금 08:30–17:30 / 토·일 10:00–17:00"인데 전환 방식은 "토 08:00 ↔ 월 08:00"으로 맞지 않음. "시스템에어컨 360"은 제품명 확인 필요(무풍과의 관계 정리 필요).
- s02: "1인실·VIP 병상", "즉각적인 안전 서비스"는 입력에 없는 설정임. 무리는 아니지만 근거가 없음.
- 레이아웃: s01 제목이 "개/선"으로 어색하게 끊기고 오른쪽 절반은 '이미지 필요'. s05 제품 이미지 박스가 좁아 "이미지 / 필요 · 제품 / 컷 · ERV"로 찌그러짐. s13 제목 "…위한 다음"이 오른쪽에서 잘림. s07 2번과 3번이 같은 사진(3번은 어둡게만 처리)임.
- 자리표시 양: s06(약 15개), s07~s09, s11, s12에 '[제품]', '[내용]', '[00]%'가 많음. 부제가 '[내용]'인 장이 s06·s07·s08 세 장임.

## 4. 잘된 점

- 면담록의 악순환(직바람 민원 → 에어컨 끔 → 더위 민원), 겨울 환기 불가, 노후 설비, 쾌적한 이미지라는 핵심 과제를 정확히 뽑아냄(s04, s05).
- 키맨 구분(시설 관리팀은 교체·유지보수, 원장은 이미지, 병실은 공기질)이 s05에 깔끔하게 정리됨.
- 병실·간호스테이션·재활센터·식당·관리실처럼 요양병원 공간을 제대로 나눴고(s06), 대부분의 사진이 병원 실내라 업종감은 맞음.
- 시간대별 병실 시나리오(s07 14:00/19:00/02:00)는 이사장이 이해하기 쉬운 형식임.
- 메모의 "ERV 묶어서" 방향은 덱 전반에 반영됨.

## 5. 재사용할 장표

- s04: 과제 3개 구조. 사진 2장(재활실, CT 판독)은 교체
- s05: 3열 가치 구조. [제품]에 무풍 계열 제품명을 넣고 이미지 박스를 정리하면 사용 가능
- s07: 1~3열(입원 첫날, 저녁 환기, 새벽 저소음). 4열은 '중앙제어로 원격 점검'으로 교체
- s02: 카드 01~03 문구
- s10: 공간별 솔루션 틀. 사진과 '교실' 문구 교체
