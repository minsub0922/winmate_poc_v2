# 솔루션 이미지 검토 브리프

Winmate(삼성 B2B 제안서 도구)의 '솔루션' 카드(17개)와 상세 갤러리에 쓸 실제 이미지를 고르는 작업입니다. 지금은 대부분 일러스트(더미)로 보입니다.
솔루션 목록: `/home/claude/media/review/solutions.json` (id · 이름 · 분류 · 설명 · 키워드).

시트는 두 종류입니다. 배치 파일: `/home/claude/media/review/batch_sol.json` (항목: `sheet` · `key` · `title` · `imgs`[n · id · alt · ctx(이미지 주변 글) · size · role(어느 페이지에서 왔는지)]).

1. `solution:<id>` 시트 — 그 솔루션의 공식 페이지(samsung.com/sec/business 솔루션 페이지, 해외 삼성 비즈니스 페이지, vxt.samsung.com, samsungknox.com, 앱 소개 페이지)에서 받은 이미지.
2. `pool:industry` 시트 — samsung.com/sec/business 업종 페이지(호텔 · 요식 · 제조 · 건설 · 공공 · 금융 · 교육 · 병원 · 운송 · 통신 · 모바일 · 사이니지 · 프린팅)에서 받은 이미지. 이 중 **어떤 솔루션을 보여 주는 이미지인지** 골라 연결합니다. 특히 지금 이미지가 하나도 없는 `content`(콘텐츠 제작 지원) · `partnerapp`(파트너 앱 · 주문 결제 연동) · `safety`(안전 · 관제) · `unmanned`(무인 과금 · 출입) · `care`(케어 · 유지관리) · `knoxcapture` · `dex` · `smartthings`를 잘 찾아 주세요. ctx(이미지 옆 글)가 판단에 큰 도움이 됩니다.

시트를 Read 도구로 직접 보고, 시트마다 결과 파일을 `/home/claude/media/review/out/<key의 ':'와 '|'를 '_'로>__<시트 파일명>.json`에 씁니다.

```json
{"key": "solution:magicinfo", "sheet": "solution_magicinfo.jpg", "items": {
  "1": {"k": 1, "kind": "screen", "rep": 3, "d": "콘텐츠 스케줄 편집 화면"},
  "2": {"k": 0, "kind": "other", "rep": 0, "d": ""}
}}
```
pool 시트는 항목마다 `"sol": ["partnerapp"]`처럼 연결할 솔루션 id 목록을 더합니다(없으면 k=0). solution 시트에서도 그 이미지가 **다른** 솔루션을 더 잘 보여 주면 `"sol": ["다른 id"]`를 적습니다(적지 않으면 시트의 솔루션).

- `k` 1 = 쓴다 / 0 = 뺀다. 시트의 **모든 번호**에 항목을 씁니다.
- `kind` `screen` 솔루션 화면 · 대시보드 · 앱 UI / `scene` 솔루션이 쓰이는 현장(공간 + 기기) / `people` 사람이 솔루션을 쓰는 장면 / `product` 솔루션과 함께 쓰는 기기 컷(제어기 · 키트 · 단말) / `diagram` 구성도 · 연동도 / `kv` 솔루션 대표 키 비주얼. 빼는 것: `text` 글 · 배너 위주 / `icon` 아이콘 · 로고 · 배지 / `dup` 거의 같은 이미지 / `other` 이 솔루션과 무관(일반 제품 홍보, 이벤트 배너, 다른 제품군) / `bad`.
- `rep` 솔루션 카드 썸네일로 0~3. 3 = 이 솔루션이 무엇인지 한눈에 보이는 이미지(화면 + 쓰는 공간, 또는 대표 화면). 솔루션마다 rep 3이 최소 하나.
- `d` 보이는 것을 한국어 30자 이내(예: "매장 사이니지 원격 배포 대시보드", "관리자 태블릿의 지점별 에너지 화면"). 지어내지 않음.

## 기준

- 영문 UI · 영문 문구가 있는 해외 페이지 이미지도 화면 자체가 좋으면 씁니다.
- 일반 하드웨어 제품 사진(TV · 에어컨 단독)은 그 솔루션의 핵심 기기(예: SAC 제어 시스템의 중앙 제어기, Wi-Fi KIT, b.IoT 관제 화면)일 때만 씁니다.
- 판단이 애매하면 쓰는 쪽으로, 단 솔루션과의 연결이 불분명하면 빼는 쪽으로.

끝나면 솔루션별로 쓴 이미지 수와 rep 3 개수, 그리고 이미지가 0~2장뿐인 솔루션을 짧게 보고합니다.
