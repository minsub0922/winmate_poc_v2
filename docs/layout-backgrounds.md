# PPT 레이아웃 배경 사진

PPT 레이아웃의 **고쳐서 My에 저장/레이아웃 고치기**에서 오른쪽 배경 설정의 **배경 사진 선택**을 누른다. 현재 장에 맞는 사진을 먼저 추천하고 나머지 사진을 이어서 보여준다. 업종·장면 검색, 16개 업종 필터, 내 사진 업로드, 마우스 확대 미리보기를 지원한다.

추천은 현재 시트에 실제로 적힌 문구, 레이아웃의 업종, 파트 유형, 제안서 업종을 사용한다. 같은 업종을 우선하고 장면 제목과 문구의 일치를 추가 반영한다. 전체 사진은 중복 없이 추천과 나머지 목록에 나누어 표시한다. 모델 응답을 흉내내는 AI 추천은 사용하지 않는다.

49개 원본과 49개 썸네일을 `app/data/backgrounds/`에 확보했다. 16개 업종별로 대표 사진 1장과 삼성 공식 현장/연출 사진 2장씩, 업종 공통 사진 1장이다. 원본은 앱에 이미 포함된 사진에서 재사용하며 원본 파일은 변경하지 않는다. 업종 표지 사진은 기존 앱 이미지로 구분하고 삼성 공식 출처로 표시하지 않는다. 삼성 사진의 원문 페이지·원본 URL과 모든 사진의 기존 경로는 `sources.json`과 `web/src/domain/templates/backgrounds.json`에 남긴다. API는 `/img/backgrounds/`에서 제공하며 동결된 `reference/live/` 파일과 별도로 보관한다.

사진을 고르면 My 템플릿의 IndexedDB에 함께 저장한다. 배경색 선택은 사진을 제거하고, 사진 지우기와 되돌리기/다시 하기도 지원한다. 새로고침·재편집·공유에서 사진이 유지된다.

배경 효과는 **원본·연하게·흰색·검정·파랑·도트·블러** 프리셋으로 시작할 수 있다. 사진 농도(0–100%), 블러(0–30px), 흰색·검정·파랑·직접 고른 덮개 색과 강도(0–100%), 도트 강도(0–100%)와 크기(4–32px)를 각각 조절하고 함께 적용한다. 도트는 사진을 실제 색상 점으로 변환한 결과이며, 블러와 농도는 앞쪽 글자·제품 사진에 적용하지 않는다. 기존 전면 사진 표지에서도 효과를 바로 적용할 수 있다.

원본 사진은 `data-bg`, 조절 값은 `data-bg-effects`, 처리된 미리보기는 `data-bg-rendered`로 분리한다. 사진을 바꾸어도 조절 값을 유지하며 **원본**을 누르면 원래 사진에서 모든 효과를 해제한다. 미리보기와 원본을 모두 My 이미지 저장소에 담아 재편집·공유에서도 원본을 보존한다. 이전 버전의 흰색/검정 틴트는 같은 시각 결과의 효과 설정으로 읽는다. PPTX에는 같은 렌더러로 만든 16:9 배경 사진을 넣으며, 실제 배경 픽셀이 화면 미리보기와 일치하는지 검사한다. 글자·이미지·도형은 배경에 합치지 않고 편집 가능한 요소로 유지한다.

```sh
# 배경 파일·썸네일·출처 대장을 다시 생성
npm --prefix app/web run build:backgrounds
# 자산/업종 전체 범위, 추천, 편집·저장·새로고침·PPTX 실제 검사
npm --prefix app/web run test:backgrounds
```

결과 화면과 PPTX는 `app/tests/output/backgrounds/`에 저장한다. 원본 장표의 편집·저장 회귀 검사는 `node app/tests/layout-editor.mjs`로 실행한다.
