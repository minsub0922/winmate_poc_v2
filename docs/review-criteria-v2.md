## 단일 원본과 실제 평가

정본은 `app/web/src/domain/review/schema.json`이다. 프런트의 영역·기준·적용 조건, Agent KB의 criteria/rubrics/라우팅 계층을 이 원본에서 만든다. `app/scripts/export_agent_data.mjs`로 런타임 KB를 생성한다. 기존 수집·연구용 `poc/test/proposal_score` 자료는 수정하지 않았다.

API는 새 기준에 맞춰 자동 관찰 메모를 통합하고 삭제한 MK3 메모를 버린 뒤, 실제 AI 라우팅 → 1·2·3점 채점 → 가중 집계를 수행한다. 시각 기준은 새 DQ ID에서도 실제 이미지를 비전 모델에 전달한다. 오류를 규칙 점수로 대체하는 경로는 여전히 거절한다.

## 기존 기록 보존

새 기록은 `criteriaVersion: 2`를 저장한다. 버전이 없는 이전 기록은 v1의 7개 영역·54개 기준과 원래 점수를 보존하며 `이전 기준`을 표시한다. 기준을 병합했다고 과거 AI 점수를 재평가한 값처럼 바꾸지 않는다. 다시 평가를 시작하면 새 26개 기준으로 새 기록을 만들며 이전 수동 선택 ID는 중복 없이 병합한다. 시뮬레이션의 기존 13개 연습 기준과 점수도 v1 참조로 고정해 이번 검토 기준 개편의 영향을 분리했다.
