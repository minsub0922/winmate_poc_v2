# 정밀 평가 기준 v4 — 2026-10-20

이 문서는 이전 평가 방식의 기록이다. 현재의 영업 제안서 맥락 기준과 85점 기준점은 `review-criteria-v5.md`를 따른다.

사용자가 지정한 4개 카테고리·24개 기준과 영역별 25% 배점은 유지한다. 이전의 항목별 1·2·3점(화면 표시 0·50·100점)은 단순 언급과 충분한 검증을 구분하기 어려웠다. 각 항목에 역할이 다른 체크포인트 4개를 정의하고, 총 96개를 독립적으로 0~4단계로 평가한다.

| 단계 | 의미 | 판단 |
| --- | --- | --- |
| 0 | 미충족 | 요소 부재 또는 제공 자료에서 명백한 오류·충돌 확인 |
| 1 | 언급 | 일반론·주장만 있고 판단에 필요한 구체 내용 부족 |
| 2 | 구체화 | 대상·수치·방안은 있으나 핵심 근거·조건·검증 누락 |
| 3 | 근거 충족 | 필수 조건과 범위가 제공 자료의 근거로 확인됨 |
| 4 | 교차 검증 | 자료 대조·검산·수용 기준·예외 검토로 완결성을 입증 |

항목 점수는 네 단계의 합계 ÷ 16 × 100이다. 한 체크포인트가 한 단계 개선되면 항목 점수는 6.25점 높아진다. 영역·종합 점수는 기존 가중 평균을 사용하되 현재 버전은 소수 첫째 자리까지 표시한다. 목표 평균·분포·일괄 감점이나 고정 비율의 하향 조정은 없다.

체크포인트는 사실·실증(`fact`), 실행 계획(`plan`), 문서 내용·논리(`document`), 실제 화면·측정(`visual`)으로 구분한다. 가상 자료·목표·가정은 검증된 실적과 구분하며 익명 고객명 자체를 감점하지 않는다. 미래 계획은 실행 전이라는 이유로 감점하지 않고 책임·범위·조건·검수·예외 대응의 완결성을 본다. 실제로 보지 않은 화면·접근하지 않은 외부 자료는 확인했다고 추정하지 않는다. 같은 문제는 담당 기준에서 한 번만 평가한다.

서버는 실제 AI가 선택한 체크포인트 단계와 이유를 보존하고 점수만 산술 계산한다. 각 단계에는 근거 수준과 이유가 필요하고, 4단계에는 교차 확인 설명이 필요하다. 모델은 장표 원문의 ID를 선택하며 서버가 그 원문과 장 번호를 연결한다. 존재하지 않는 ID·누락·중복·범위를 벗어난 단계는 거절하고 제한적으로 수정 요청한다. 이는 인용의 출처 일치를 확인하는 절차이며, 인용이 주장을 충분히 뒷받침하는지는 여전히 AI의 판단과 사용자의 검토가 필요하다. 외부 사이트를 새로 조사하거나 실측 결과를 만든 것은 아니다.

UI의 전체 평가 기준 창에는 다섯 단계의 정의와 각 항목의 세부 체크포인트가 표시된다. 차트 hover와 세부 점수에는 네 단계·점수·이유·확인 내용을 보인다. 서버 원문·Markdown 내보내기도 새 방식과 이전 방식을 구분한다. v1/v2/v3의 기존 이름·기준·점수는 해당 버전으로 읽는다.

## 장별 보기의 hover·상세

장표에 마우스를 올리거나 키보드 포커스를 두면 실제 원본 렌더러로 확대본을 보여주고, 그 아래 해당 장이 근거로 연결된 평가 항목과 체크포인트 점수를 표시한다. hover 안으로 마우스를 이동해 읽고 확대본을 클릭해 상세를 열 수 있다. 클릭한 상세 팝업은 데스크톱에서 원본 왼쪽·평가 오른쪽, 좁은 화면에서는 원본 위·평가 아래로 배치한다. 이전/다음·화살표 키·Escape를 유지한다.

표시하는 항목 점수는 제안서 전체 평가 점수이며, 해당 장에 연결된 체크포인트만 골라 표시한다. 각 장을 별도로 다시 채점한 점수처럼 표시하지 않는다. 연결 근거가 없는 장은 점수를 만들지 않는다. 평가 원본과 다른 제안서가 명시적으로 연결되면 기존 장별 근거를 새 제안서에 잘못 붙이지 않는다.
