# 제안서 맥락 평가 v5 — 2026-10-20

4개 카테고리·24개 기준·96개 체크포인트와 영역별 25% 배점은 유지한다. v4의 4단계는 교차 검증의 완결성을 요구하고, 가정에는 2단계·50점 상한을 두어 초기 영업 제안서를 계약서·실증 보고서처럼 평가하는 문제가 있었다. 이번 버전은 고객이 지금 요청받는 결정을 내리기에 제안이 충분한지를 평가한다.

| 단계 | 환산점수 | 제안서에서의 의미 |
| --- | ---: | --- |
| 0 | 0 | 필수 요소가 없거나 중대한 오류·모순 |
| 1 | 40 | 일반론·언급뿐이라 고객 판단이 어려움 |
| 2 | 65 | 방향은 이해되나 현재 결정에 필요한 일부 내용 보완 |
| 3 | 85 | 제안 범위에서 고객의 다음 의사결정에 충분 |
| 4 | 100 | 고객 맞춤 연결·설명·대안·정합성이 특히 설득력 있음 |

항목 점수는 네 체크포인트의 **환산점수 평균**이다. 영역과 종합은 기존 가중 평균을 유지한다. 충분한 보통 영업 제안서의 기준점을 85점으로 정했으며, 샘플 평균에 일괄 가산·배율·순위·강제 정규화를 적용하지 않는다. 모델에는 샘플 평균을 특정 값으로 맞추라는 지시를 보내지 않는다. 모델이 선택한 단계를 위 공개 환산표로 계산한다.

모든 체크포인트 요구사항을 제안 단계에 맞게 정리했다. 파일럿 승인 제안은 그 범위의 비용·효과·계획으로 판단하며, 아직 승인 요청하지 않은 전사 확산의 확정 TCO나 계약 SLA를 요구하지 않는다. 주요 역할을 문장으로 설명해도 충분하며 별도 RACI표·정량 위험 행렬·NPV를 일괄 요구하지 않는다. 제공된 고객 맥락과 명시적·합리적인 가정은 제안 단계의 정상 자료로 인정한다. 외부 원문·일부 화면이 평가 환경에 없다는 한계를 문서 결함으로 만들지 않는다.

현재 제시해야 할 내용과 후속 검증을 구분한다. 대안 목록이나 “향후 비교하겠다”는 문장은 지금의 차별성 설명을 대신하지 않으며, 비용·효과를 산정할 계획만 있고 현재 판단할 금액·산식이 없으면 보완 대상이다. 반대로 이미 명시한 가정과 산식을 파일럿으로 검증하는 계획은 정상적이다. 실제 산술·단위 오류, 자료 간 모순, 과장된 성과 보장, 핵심 요구 누락은 계속 평가한다. 고객·RFP가 상세 검수·시험 자료를 요구한 경우에는 그 요구를 적용한다.

가독성은 실제 읽기와 핵심 인지를 판단한다. 어절·박스 수가 많다는 사실만으로 감점하거나 메시지형 제목과 목차·부록용 라벨형 제목의 공존을 불일치로 간주하지 않는다. DQ1에서는 가정의 불확실성을 산술 오류처럼 중복 감점하지 않는다.

## 동일 원본의 실제 재평가

직전 예시의 본문을 바꾸지 않고 현재 기준으로 실제 서버 AI 재평가를 진행했다.

| 예시 | 새 종합 | 고객 | 실행성 | 경쟁력 | 완성도 |

현재 입력은 가상 고객 예시이며 실제 외부 조사나 도입 검증을 한 것이 아니다. 출처 ID는 실제 장표 문구와 연결한다. 다른 척도의 전후 점수 차이를 제안서 자체의 개선·악화로 해석하지 않고 같은 버전에서 재평가해 비교한다. 실제 결과와 본문·화면 해시는 `migration/evidence/linked-review-examples.json`에 보존한다.
