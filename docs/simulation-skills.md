# 제안 시뮬레이션 스킬 — 2026-10-20

활성 시뮬레이션 입력창의 @ 메뉴는 전체 탭을 없애고 제품을 기본으로 시작한다. 탭은 제품·솔루션·유관사례·스킬이다. 다른 화면의 공용 @ 메뉴에는 기존 기본 동작을 유지한다.

미리 구성한 스킬은 경쟁사 분석, 맞춤 제품 제시, 솔루션 구성 제안, 유관 사례 탐색, 투자효과·비용 정리, 고객 우려 대응, 파일럿·실행 계획, 의사결정 요약의 8개다. `app/web/src/domain/simulation/skills.json`의 정의를 UI와 서버가 공유한다.

@ 메뉴의 스킬 탭은 강조 색상·sparkle 아이콘·AI 배지로 구분한다. 제품 탭을 기본으로 유지한다. @ → 스킬 → 원하는 스킬을 선택하면 즉시 실행 팝업을 열고 실제 엔진을 호출한다. 입력 중인 요청은 @ 선택 문구를 제거한 상태로 함께 전달한다. 현재 공개된 고객 정보·요구사항·최근 대화·실행 시점의 연결 제안서·명시적 제품 참조를 보내 검색 계획을 만든다. 아직 드러나지 않은 페르소나 우려, 내부 평가 점수, 사용하지 않은 스킬 결과는 전달하지 않는다.

서버는 실제 제품 DB와 정본 솔루션·사례·Best Scenario 자료를 검색한다. Best Scenario는 가상 고객의 구성 참고 자료로 표시해 실제 도입 실적과 구별한다. 연결한 제품의 상세 묶음도 조회한다. 8개 스킬 모두 실제 Google Search grounding을 실행한다. 검색 계획은 현재 스킬의 목적에 맞춰 제품 사양·운영 가이드·도입 사례·비용 구성·실행 조건 등을 탐색한다. 검색 출처가 없으면 핵심 검색어로 실제 검색을 한 번 더 실행하고, 그래도 출처가 없으면 실패를 표시한다. 공개 검색어에는 고객·개인명·연락처·금액 표기를 제거하는 절차를 적용한다.

찾은 자료로 별도의 실제 AI 답변을 생성한다. 분석·추천·비교마다 제공된 출처 ID를 연결하며, 추천 제품·솔루션·사례는 실제 검색 자료의 ref인지 검사한다. 동적 출처 목록의 검증은 서버에서 수행해 모델의 복잡한 enum 스키마 제약에 의존하지 않는다. 없는 참조·출처·비교 근거는 거절하고 제한적으로 다시 요청한다. 실제 웹 검색 출처가 없으면 경쟁사 사실을 모델 기억으로 대체하지 않는다. 출처의 존재와 연결을 검사하는 절차이며 모든 주장의 진위를 독립 검증했다는 뜻은 아니다.

팝업의 5단계(대화 맥락 → 앱 자료 탐색 → 웹 검색 → LLM 분석 → 답변 3개 생성)는 실제 실행 이벤트로 갱신한다. 실제 검색어와 수집한 자료를 단계별로 확인할 수 있다. LLM이 생성하는 공개 분석 요약을 provider의 streamGenerateContent → 서버 SSE → 브라우저로 점진적으로 표시한다. 숨은 사고 과정이나 임의의 진행률을 표시하지 않는다. 스트림 완료 시 실제 모델·토큰 사용량도 집계한다. 분석 요약과 원자료를 바탕으로 별도의 구조화된 LLM 호출에서 접근 방식이 다른 답변 3개를 생성한다. 각 후보의 제목·활용 설명·본문·출처, 정확히 3개인지와 중복 여부를 검증한다. 추천 ref는 작은 enum과 서버 검증으로 실제 검색된 자료에 제한한다. 맥락별 분석·대안 비교·추천 자료·확인할 사항·다음 행동도 함께 보존한다. 대화 로그에는 간결한 자료 준비 카드를 남기고 팝업을 다시 열어 작업 과정과 답변을 확인할 수 있다. 웹 검색이 있으면 API가 제공한 Google 검색 제안 HTML을 스크립트를 허용하지 않는 iframe으로 표시한다. 진행 단계는 SSE로 수신하고 취소·오류·현재 맥락으로 재시도를 지원한다.

스킬 실행은 고객 발언이나 영업 턴으로 넣지 않으므로 만족도·제안 품질·숨은 우려 상태를 바꾸지 않는다. 사용자가 3개 후보 중 `이 답변 사용`을 누르면 실제 제품명·솔루션을 편집 가능한 참조 칩으로 바꾼다. 사용자가 직접 보낼 때만 선택한 후보의 출처를 해당 영업 메시지에 붙여 고객 역할·평가·총평이 그 근거를 읽도록 한다. 실제 답변에 사용한 자료는 제안서로 넘길 때 참조 목록과 관련 자료에도 보존한다. 준비만 한 결과는 고객에게 전달한 자료처럼 취급하지 않는다.

팝업을 닫아도 작업은 계속되며, 자료 준비 카드로 다시 열 수 있다. 실행 중지 버튼은 실제 요청을 취소하고 늦게 도착한 결과를 버린다. 오류 후 재실행은 최신 맥락과 원래 요청을 다시 읽는다. 재실행 시 연결 자료 이름들을 요청 본문으로 덧붙이지 않는다. 완료 결과와 단계별 자료·분석은 기존 시뮬레이션 기록과 함께 보존한다. 예전 단일 초안 기록도 열어서 사용할 수 있다. 새로고침 시 진행 중인 실행은 중단 상태로 표시하고 자동 재실행하지 않는다. 숨은 고객 정보나 이전 기록을 삭제하지 않는다.
