# 제안서 검토 상세 화면 개편

2026-10-20. 현재 앱 `app/web/src/pages/ReviewPage.jsx`와 `components/review-report.jsx`에 적용했다.

- 오른쪽 패널을 없애고 종합평 → 장별 보기 → 먼저 고칠 것 → 기준별 평가 순서로 한 열에 배치한다.
- 고객사·업종·제품·솔루션·장 구성은 `이렇게 읽었어요` 버튼에 마우스를 올리면 표시한다. 키보드 포커스와 터치도 지원하며 카드 안의 내용을 읽거나 관련 장표를 열 수 있다.
- 영역별 점수(새 기준 4개, 이전 기록은 당시 영역 수)는 종합평 아래의 간단한 읽기 전용 요약이다. 클릭·필터 기능은 없다.
- 장별 보기는 전체 폭의 가로 스크롤 목록이다. 모든 저장된 장을 표시하며 이전/다음 버튼과 기본 가로 스크롤을 지원한다. hover는 확대 원본 위·점수 아래, 클릭한 상세는 데스크톱 원본 왼쪽·평가 오른쪽 구조다. 좁은 화면은 위아래로 배치한다.
- 우선 수정 항목은 데스크톱 3열, 태블릿 2열, 모바일 1열 그리드다.
- 기준별 평가는 새 검토에서 4개 영역의 스파이더 차트로 표시한다. 이전 기록은 당시 기준을 사용한다. 각 축은 실제 검토 기준이다. 점이나 기준 이름의 hover/포커스에서 점수·설명·평가 근거·수정 방법·근거 장표를 확인한다. 미평가 기준은 빈 점과 상세 설명의 `미평가` 문구로 구별하며 0점으로 표시하지 않는다.
- 스파이더 차트 아래의 중복 점수 목록은 제거했다. 상세 hover는 해당 차트의 좌우 바깥에 배치하고, 옆 공간이 280px 미만인 화면에서는 차트 아래에 공간을 확보해 표시한다. 54개 기준 모두에서 설명 영역과 차트가 겹치지 않는지 확인했으며 키보드 포커스·hover 카드 안으로 마우스 이동·Escape 닫기를 지원한다.
- 검토 홈의 카드도 같은 원본 렌더러로 앞 3장의 실제 PPTX 또는 PDF를 표시한다. 원본을 다시 연결하면 카드가 즉시 갱신된다. 원본이 없는 기록은 연결 안내를 표시하며 홈의 `먼저 고칠 것` 문구와 간략 도형 배치도는 제거했다.
- 서버의 추가 채점 원문은 접힌 영역에 보존한다. 평가 계산과 원래 점수는 바꾸지 않는다.

## 연결된 제안서의 장별 보기

연결된 제안서가 있으면 업로드 파일의 미리보기보다 그 제안서에 저장된 레이아웃을 우선 표시한다. `previewProposalId`, 기존 `linkedId`, 이전 `proposalId`의 명시적인 연결만 사용하며 고객명·제목으로 다른 제안서를 추정하지 않는다. `deckOrder`와 실제 `Slide` 렌더러를 사용해 표지부터 전체 장표를 표시하고, 문구·그림·배경의 저장된 overrides와 My 템플릿을 그대로 반영한다.

업로드 문서가 없어도 목록·확대·이전/다음·키보드 이동이 동작한다. 제안서를 수정하면 화면도 갱신된다. 검토 홈의 앞 3장도 같은 연결을 사용한다. `연결 제안서` 선택에서 재업로드나 재채점 없이 장표를 보여줄 제안서를 지정할 수 있다. 연결은 검토 설정에 보관하며 기존 평가 근거·점수와 요구사항 비교용 연결은 변경하지 않는다. 연결 대상이 삭제되었거나 레이아웃이 없는 경우에는 복구 안내를 표시한다.

브라우저 검증에서 업로드 문서 12장과 연결된 제안서 14장을 함께 준비해 연결된 전체 14장이 우선되는지 확인했다. 이후 업로드 문서를 삭제하고도 표지 순서·사용자 이미지·수정 문구·14장 확대·연결 변경·새로고침·홈 썸네일·점수 불변·삭제/빈 제안서 처리를 확인했다.

## 실제 장표 표시와 이전 기록

PPTX는 My 가져오기에서 사용하는 `convertPptx`로 전체 HTML·도형·글자·표·이미지를 변환해 IndexedDB에 보존한다. 썸네일과 확대 화면에 같은 HTML을 사용한다. 이미지 Blob은 화면을 여는 동안에만 URL로 만들고 닫거나 문서가 바뀌면 해제한다. 변환 HTML은 스크립트를 허용하지 않는 iframe에서 원래 1280×720 좌표로 표시한다.

PDF 또는 함께 올린 PDF가 있으면 실제 페이지 이미지를 우선 표시한다. 일반 검토의 기존 80쪽 표시 제한을 제거했다. RFP 등 원문 읽기용 `textOnly`의 기존 1,000쪽 제한은 유지한다. PPTX 브라우저 변환의 지원 범위는 기존 My 가져오기와 같으며, 변환기가 반환한 이미지·폰트 등의 경고도 목록 아래에 표시한다. 정확한 PDF 화면을 함께 연결할 수도 있다.

과거 저장 기록과 일부 예시에는 원본 없이 도형 좌표만 남아 있다. 이런 기록을 원본처럼 재구성하지 않는다. 먼저 연결된 제안서의 레이아웃을 사용하며, 연결할 제안서가 없고 업로드 원본 화면이 필요한 경우에는 `원본 연결`에서 같은 PPTX 또는 PDF를 선택하면 장수와 본문을 대조한 후 실제 화면을 저장한다. 다른 제안서는 거절하고 기존 평가 결과를 유지한다. 저장 공간 부족 등으로 저장하지 못하면 성공 메시지를 표시하지 않는다. 텍스트 문서는 추출한 본문을 그대로 표시한다.

## 원본과 연결된 검토 예시

현재 예시는 `review-criteria-v5.md`의 4영역·24항목·96체크포인트를 사용한다. 카페 22장, 호텔 41장, 대학 19장에 고객 판단·당사 실행/위험 대응·파일럿 투자 가정·근거/고지 부록 네 장씩을 보강했다. 새 원본 ID와 `linkedId`·`previewProposalId`를 직접 연결하고 전체 장표를 실제 AI로 재평가했다. 모델이 채점한 96개 체크포인트와 실제 호출 13·13·12건의 결과를 확인했다. 제안에 충분한 수준을 85점으로 보는 공개 환산표를 사용한다. 열람·교체 때 모델을 다시 호출하지 않는다.

관리자 브라우저에서 수정하지 않은 기존 기본 검토만 한 번 교체하며 개인 기록, 수정한 검토나 원본은 당시 평가와 함께 보존한다. 이전 제안서 원본·수집/참고 자료와 v2 예시 데이터도 유지한다. 양쪽 저장이 완료된 뒤 seed marker를 `admin-linked-review-examples-5`으로 올리며 완료 후 삭제한 예시는 되살리지 않는다.

원본과 모델 결과는 `domain/review/linked-review-examples.json`, 평가 화면은 `public/assets/review-examples/`, 생성 근거는 `docs/migration/evidence/linked-review-examples.json`에 보관한다. 재생성 명령 `node app/scripts/build_linked_review_examples.mjs`는 설정된 모델을 실제 호출하는 명시적 작성 도구다.

## 검증

```sh
npm --prefix app/web run test:review
npm --prefix app/web run test:review-examples
make test
npm --prefix app/web run build
```

전용 브라우저 검사는 실제 카탈로그·예시 데이터·PPTX/PDF 입력을 사용하고 모델 네트워크 접근은 차단한다. 사용자 저장소와 별개의 브라우저 컨텍스트에서 수행한다.

기존 검토 화면 검사 32개가 통과했다. 레이아웃·hover·포커스·Escape·가로 스크롤·원본 재연결·평가 점수 불변·IndexedDB 재로딩·단일 열 확대·키보드 이동·잘못된 원본 거절·실제 포함 이미지 디코딩·81쪽 PDF 전체 이미지·900/390px·다크 모드·홈의 실제 장표 표시·원본 재연결 즉시 갱신을 확인했다. 스크린샷과 결과는 `app/tests/output/review-report/`에 저장한다.

현재 API 회귀 검사는 193건과 subtest 74건이 통과했으며, 기존 전송·관리자 샘플 히스토리·제품·작업 계약 검사도 통과했다.

연결·보존 단위 검사 20건, 기존 검토 화면 검사 32건, 연결 예시 브라우저 검사 17건도 통과했다. 연결 예시 전용 브라우저 검사는 신규 초기화·기존 기본 예시 교체·개인/수정 기록 보존·전체 장표·확대 이동·새로고침·삭제 후 미복원·일반 계정 제외·모델 호출 없음에 집중한다. 화면과 결과는 `app/tests/output/linked-review-examples-ui/`에 보관한다.

현재 4영역·24항목·96체크포인트와 이전 v1/v2/v3 보존 정책은 `review-criteria-v5.md`를 따른다. 기존 v2 통합 이력은 `review-criteria-v2.md`에 남긴다.

기준별 평가의 항목명은 화면 크기에 따라 축소되지 않는 실제 14px, 영역 제목은 17px, 평가 개수는 13px로 표시한다. hover의 제목·점수·본문도 확대했다. 차트는 기본 2열(넓은 화면 3열, 모바일 1열)이며 항목명 줄바꿈과 여백을 조절한다. 390/900/1500px에서 실제 글자 크기·겹침·잘림을 검사한다. 최상단 안내 배너는 제거했으며 버전·예시·시각 분석 범위 등 부가 정보는 기존 `이렇게 읽었어요` 안에 보존한다.
