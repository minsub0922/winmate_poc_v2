# Winmate v2

고객 요구사항 → Storyboard 파트 → PPT 레이아웃 선정 · 채우기 → PPTX 내보내기까지 한 흐름으로 이어지는 제안서 작업대.
배포본: `dist/index.html` 한 장 + `dist/img/` (Claude 아티팩트로 게시됨).

## 제안서 검토
- 홈의 점선 영역에 파일을 끌어다 놓거나 눌러서 올리면 바로 평가해요. PPTX와 같은 내용의 PDF를 함께 올리면 PPTX로 구조(겹침 · 넘침 · 글자 크기 · 노트)를, PDF로 장표 화면을 봐요(숨김 장은 건너뛰고 맞춰요).
- 54개 기준 중 제안서 내용에 맞는 기준만 적용해요(제품이 없으면 제품 기준 제외 등). 제외 이유는 리포트 아래에 나와요.
- 기준마다 자동 점검 신호를 먼저 계산하고, AI가 그 신호와 본문(장 번호 포함)을 읽고 0~100점 · 근거 · 고칠 방법을 써요. AI를 못 쓰면 자동 점검 점수로 채점해요.
- `dist/lib/`의 pdf.js(3.11.174) · 한글 CMap은 PDF를 올릴 때만 불러와요. 아티팩트 게시 때 `lib/` 파일도 함께 올려야 해요.
- 아티팩트 권한: `sample`에 `images: true`(장표 이미지 평가), `downloads`(리포트 저장).

## B2B 전략 시뮬레이션 (BETA)
- 요구사항 하나와 난이도를 고르면 최종 제안 대상자(가상 인물)가 먼저 말을 걸어요. 내 답마다 고객 만족도(±15 이내로 움직임)와 제안 품질(제안서 검토 기준 13개를 4개 영역으로)을 매기고, 입력창 위에 다음 말 3개를 추천해요 — 드러난 우려 대응 · 가장 약한 기준 · (성공 기준 근처면) 결정 요청.
- 숨은 우려는 난이도마다 1 · 2 · 3개, 관련 주제가 나오면 고객이 하나씩 꺼내요. 만족도가 성공 기준 이상이고 우려가 풀린 상태에서 결정을 요청하면 수락(설득 성공), 15 이하면 미팅이 끝나요.
- AI는 `sample`(quick 티어, cache: false)로 한 턴에 한 번 불러요. AI를 못 쓰는 화면(로컬 미리보기 등)에서는 규칙 기반 고객 · 자동 점검으로 같은 흐름을 보여 줘요. `build/test-sim.mjs`는 규칙 모드와 가짜 스트리밍(mock) 모드를 함께 점검해요.
- 최종 제안 대상자는 난이도 3단계 × 남/여 6명(`sim/profile.js` PERSONAS: 이름 · 나이 · 경력 · 성향 · 한마디)이고, 얼굴은 `ui/persona.jsx`의 SVG 일러스트예요(실제 인물 사진 아님). 표정은 지금 만족도 무드(만족 · 호의 → 웃음, 중립, 의심 · 불만 → 찡그림)를 따라 바뀌어요. 설정 화면에서 성별을 고르고, 오른쪽 패널 맨 위 인물 카드에 마우스를 올리면 프로필 전체가 보여요.
- 추천 답변은 제목 + 한 줄만 보이고 마우스를 올리면 전체 문장 · 채우는 기준이 보여요. 대화 화면 머리에는 인물과 '미팅 마무리'만 둬요(좁은 화면에서는 인물을 누르면 평가 패널이 열려요).
- 설정 화면은 위에서부터 머리(전략 Agent · 제목 · 한 줄) → 진행 과정(읽기 전용 흐름도: 4단계 + 얻는 것 3가지, 누르는 요소 · 접기 없음) → 요구사항 · 만날 고객 카드 → 그 바로 아래 가로로 긴 '시뮬레이션 시작' → 최근 시뮬레이션 목록 순이에요. 요구사항 바꾸기 · 프로필 전체는 팝업으로 열려요. 미팅 총평에는 '전략 Agent 총평' 표시가 붙어요.
- 고객 프로필: '만날 고객' 카드의 '바꾸기'로 기본 6명 · 내 프로필 중에서 고르고, '새 프로필'(카드 머리 · 프로필 팝업 · 고르기 팝업)로 직접 만들어요. 기본 프로필은 '고쳐서 새로 저장'으로 복사본을 만들고, 내 프로필은 저장(덮어쓰기) · 새 프로필로 저장 · 지우기가 돼요. 사진 30종에 피부 · 머리색 · 옷 · 안경을 바꿀 수 있고, 이름 · 나이 · 직책(비우면 요구사항의 대상자) · 경력 · 성향 · 평소 한마디 · 의사결정 스타일 · 난이도를 정해요. 기본 인물은 난이도를 바꾸면 그 난이도의 인물로 바뀌고, 내 프로필은 사람은 그대로 난이도만 바뀌어요. 세션 기록은 얼굴을 함께 저장해 원본 프로필을 지워도 그대로 보여요. 프로필 팝업에는 시작 버튼이 없어요(시작은 카드 아래 막대).
- 메시지 입력은 `MentionEditor`에 `onEnter`(Enter 보내기 · Shift+Enter 줄바꿈 · 한글 조합 중 Enter는 무시)를 더해 썼어요.

## My 템플릿
- PPT 레이아웃 템플릿의 ‘필터’ 옆 **My**를 켜면 나만의 템플릿만 보여요. 맨 앞은 PPTX 올리기(끌어다 놓기 · 고르기), 그 아래 올린 파일별 묶음과 ‘고쳐 만든 레이아웃’. 검색 · 필터도 My 안에서 동작해요.
- PPTX를 올리면 브라우저 안에서 장마다 복원해요(서버로 보내지 않음). 검토 화면에서 저장할 장 · 이름 · 파트 유형을 고르고, 원본과 다를 수 있는 곳(EMF/WMF 그림 · OLE · 잉크 등)을 알려 줘요. 그림은 슬라이드에 보이는 크기의 2.5배까지만 남겨 저장 공간을 아껴요.
- 기존 레이아웃: 템플릿 상세의 ‘고쳐서 My에 저장’ → 편집기에서 고친 뒤 저장(원본은 그대로). My 템플릿은 상세의 ‘고치기’로 덮어쓰거나 ‘새 템플릿으로 저장’.
- 제안서에서는 Storyboard 파트의 ‘PPT 레이아웃 추가’ 팝업 추천 아래 **My 템플릿** 섹션에서 고르면 돼요(검색어를 넣으면 이름 · 글이 맞는 것만). AI 채우기 · 상세 편집 · PPTX 내보내기도 다른 레이아웃과 같아요.
- **찜**: 레이아웃이 보이는 곳 어디서나 카드 오른쪽 위 ♡(상세는 ‘찜’ 버튼). 값이 채워진 장(Best Scenario · 제안서의 장)과 빈 레이아웃은 같은 레이아웃이라도 따로 찜되고, My의 ‘찜’ 탭에서 두 묶음으로 나눠 보여요. 레이아웃 추가 팝업의 찜 섹션에서 고르면 그 값 그대로 들어가요.
- PPTX에서 온 템플릿을 내보낼 때는 원본 글꼴 이름을 그대로 쓰고(data-keep-font), 회전 · 뒤집기 · 선 밖으로 나온 화살촉도 살려요(pptx.js, data-my 루트에서만).
- 저장은 이 브라우저(IndexedDB)에만 돼요. 다른 기기 · 다른 사람과 공유되지 않고, 브라우저 데이터를 지우면 사라져요. 지운 템플릿을 쓰던 제안서에서는 그 장이 빠져요(지울 때 쓰는 곳 수를 알려 줌).
